# SpaceX-Falcon9-Landing-Prediction

## IBM Data Science Capstone Project

### Project Overview

This project analyzes SpaceX Falcon 9 launch data to predict whether the first stage will successfully land.

The project includes:

- Data Collection
- Data Wrangling
- Exploratory Data Analysis (EDA)
- SQL Analysis
- Interactive Maps using Folium
- Machine Learning Classification

### Dataset

- dataset_part_2.csv
- dataset_part_3.csv

### Machine Learning Models

- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)

### Best Model

Support Vector Machine (SVM)

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQLite
